CareerWorth planner

Privacy

Last updated November 9, 2026

CareerWorth is a career and compensation planning tool. This page describes the browser storage, sharing, backups, and optional analytics in this version of the site.

Planner information and browser storage

Your planner inputs and saved plan are stored in this browser using local storage. The selected view mode is stored in session storage. The app does not create an account or send planner values to an application server for calculation. Your browser or device provider may still back up or sync browser data according to your own settings. Clearing site data removes the locally saved plan.

Share links and backups

The address bar contains the current valid plan, including compensation, expenses, accounts, and other inputs. Anyone who receives that URL can read those values. URLs can appear in browser history, server request logs, and referrer information when navigating elsewhere. Do not include information you would not want to share. A downloaded backup contains the full plan, including scenario and account details; it is stored wherever you save it. Restoring a backup reads it in your browser and replaces the current plan only after confirmation.

Optional analytics

If analytics are configured for a deployment, analytics are off until you choose “Allow anonymous analytics.” Your choice is stored in local storage. With consent, the app sends events when opened, when you change view mode, add a comparison, create a share link, export a CSV, and grant consent to the configured PostHog service. Events include the event name and fixed labels such as view mode or export period; they do not include salary, balances, tax values, company names, scenario contents, or share-link values. Automatic page capture, exception capture, session recording, autocapture, surveys, feature flags, and person profiles are disabled. PostHog is configured for in-memory persistence and with IP collection disabled. The analytics service and hosting provider may still process technical request information, and the site host may keep operational logs; processing and retention depend on the deployment configuration and provider terms. Use “Turn off analytics” in the site footer to withdraw consent.

Hosting and external sources

The site host necessarily receives network requests to serve the app and may keep operational logs under its own configuration. The planner links to third-party sources; when you follow those links, those providers handle your visit under their own privacy terms.

Children and changes

This planner is intended for adults making career and financial plans, not for children. This notice may be updated when the site’s behavior changes. The date above identifies the latest revision.
